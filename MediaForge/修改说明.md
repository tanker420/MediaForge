# MediaForge 修改说明

> 基于 https://github.com/tanker420/MediaForge 原仓库（公开版），按用户要求完成**全部 A/B/C 级问题修复** + **现代化 UI 重写** + **中文化打包模板** + **取消命令行预览**。所有改动均已在沙箱内跑通测试与 GUI 冒烟。

---

## 1. 已修复的问题（共 9 项）

### A 级（实际 Bug）

| ID | 问题 | 修复位置 |
| --- | --- | --- |
| **A1** | CLI 中 `-f/--format` 与 `--out-format` 共用同一个 argparse dest，导致 `--help` 中互相覆盖 | `app/cli.py` 拆分：`-f/--kind` → dest=`kind`，`-F/--out-format` → dest=`out_format` |
| **A2** | 音频淡出（淡出滤镜）在「预览命令」里有，实际执行却丢失 — 预览与真实不一致 | `app/core/ffmpeg_builder.py` 在 `build_command` 中探测到媒体时长后自动注入 `params["_duration"]`；`app/ui/main_window.py` 已彻底移除命令行预览（见 B6） |
| **A3** | 图片转换不支持取消（`convert_image` 没有任何 cancel 检查） | `app/core/image_engine.py` 新增 `CanceledError` 与 `_check_cancel`；`convert_image` / `_apply_geometry` / `_apply_adjustments` / `_convert_animated` 均接收 `cancel` 参数；`app/core/converter.py` 中 `run_job` 将 cancel 传到底层并捕获 |

### B 级（功能 / 测试缺陷）

| ID | 问题 | 修复位置 |
| --- | --- | --- |
| **B4** | 字幕文件路径里含 `[ ] , ;` 等字符时滤镜解析失败（仅转义了 `:` `'`） | `app/core/ffmpeg_builder.py` 新增 `_escape_filter_path`，统一转义 `: ' [ ] , ;` 并把反斜杠标准化为斜杠 |
| **B5** | `tests/test_commands.py` 整个模块在缺 ffmpeg 时跳过，导致纯字符串测试（滤镜链、转义、参数翻译）永远跑不到 | `tests/test_commands.py` 拆分：纯字符串测试**始终运行**，仅真正拼装完整命令行的测试用 `pytest.mark.skipif` 在缺 ffmpeg 时跳过 |
| **B6** | 主窗口有死代码（`idx = self.cb_kind.findData(kind)` 没人用，且整个 UI 暴露了「命令行预览」+「自定义 ffmpeg 参数」专家入口） | `app/ui/main_window.py` 完全重写：去掉命令行预览框与 `extra_args` 字段，所有操作图形化 |

### C 级（小问题）

| ID | 问题 | 修复位置 |
| --- | --- | --- |
| **C8** | UI 代码直接访问 `q._threads`（私有属性） | `app/core/converter.py` 新增公开方法 `ConversionQueue.wait()`，`main_window.py` 改为调用它 |
| **C9** | `icon.ico` 与 `icon.png` 文件名混乱（spec/installer 用 .ico，UI 既要拿 .ico 也要拿 .png） | `app/resources/icon.ico`（多尺寸 ICO，用于 PyInstaller 与安装程序）+ `app/resources/icon.png`（256×256 PNG，用于 GUI 窗口与启动图标）；`packaging/MediaForge.spec`、`packaging/installer.iss` 只引 .ico；`app/ui/main_window.py` 只引 .png |
| **缓存失效** | 切换 ffmpeg 后 `available_encoders()` 不会重新探测 | `app/core/ffprobe.py` 新增 `invalidate_caches()` 一次性清除 `find_tool` / `available_encoders` / `ffmpeg_version` 三个缓存；UI 右上角 FFmpeg 状态标签点击即可重新检测 |

## 2. UI 现代化重写（任务 #3）

原 UI 是一个保守的工具栏+表格布局，存在命令行预览框与专家字段。新版完全重写：

- **现代化布局**：顶栏 + 类别分段选择器（视频/音频/图片）+ 左文件列表卡 + 右输出设置卡 + 底操作栏
- **主题系统**：`app/ui/theme.py` 提供完整浅色 QSS：圆角卡片、渐变主按钮、胶囊进度条、微软雅黑字体栈；分段选择器、卡片标题、拖拽提示、底栏等自定义控件样式
- **自动识别类别**：拖入文件后无需手动选择类别，分段控件自动切换；切换类别时输出格式/编码器/预设/参数表单全部自动重建
- **拖拽支持**：文件可拖入表格，也可拖到窗口任意位置；目录递归收集
- **现代交互**：
  - 预设一键套用（28 个内置 + 用户预设），应用后仍可微调
  - 选择输出格式后，编码器下拉框自动限定为该容器支持的编码器
  - 编码器不可用时显示「（未安装）」后缀（基于 `available_encoders()`）
  - 表格内进度条 + 状态文字实时更新
  - 选中文件时后台线程异步探测，显示分辨率/帧率/采样率/时长/大小到状态栏
  - 完成后弹窗汇总成功/失败/取消数量 + 一键打开输出文件夹
- **危险操作锁定**：转换期间禁用「添加/移除/清空/类别切换/格式切换/参数表单/输出目录」等所有会改变任务集合的控件，仅保留「取消」按钮
- **取消支持**：进度条可取消；图片任务在主要步骤间检查取消标志并抛出 `CanceledError`
- **设置持久化**：上次输出目录、命名规则、并行任务数、覆盖选项通过 `QSettings` 记住
- **键盘友好**：Delete 键移除选中文件

### 取消的命令行相关功能

- ❌ 主窗口中的「命令预览」文本框（用户要求「不需要看到命令行」）
- ❌ 参数表单中的「自定义 ffmpeg 参数」字段（专家入口，用户要求「也不需要命令行运行」）

## 3. 打包模板中文化（任务 #4）

按国内主流安装程序的样式重写 `packaging/installer.iss`：

- **向导语言**：简体中文默认（`chinesesimplified` 第一条），英文备选
- **本地化文案**：标题 `安装 - MediaForge 全能格式转换器 1.0.0`、按钮 `安装(I) / 下一步(N) > / 上一步(B) / 完成(F) / 浏览(R)…`、欢迎页/完成页文案全中文
- **应用信息**：应用名、卸载显示名、文件属性全部带中文
- **任务项**：「创建桌面快捷方式」「将 MediaForge 加入系统 PATH」「在右键菜单中添加『用 MediaForge 转换』」
- **PATH 处理**：勾选 PATH 时追加 `%ProgramFiles%\MediaForge`，卸载时自动清除
- **版本文件**：`packaging/version_info.txt` 用 UTF-16 LE（lang 0804, codepage 04B0）写入中文产品名 / 描述

其他打包文件一并完善：

- `packaging/MediaForge.spec` — PyInstaller 配置，`console=False`（无命令行窗口），随包分发 `app/resources/`
- `packaging/version_info.txt` — Windows 文件属性（中文）
- `packaging/build_windows.bat` — 本地一键打包脚本（venv + pip + pyinstaller + Inno Setup）
- `packaging/ci/build.ps1` — CI 共用脚本（自动下载 BtbN 静态 FFmpeg → 打包 → 装包）
- `packaging/ci/build-windows.yml` — 参考模板（仓库根的 `.github/workflows/build-windows.yml` 才是真正生效的工作流）
- `.github/workflows/build-windows.yml` — 手动触发 / 打标签自动构建并发布 Release
- `如何生成安装程序.md` — 中文使用文档
