## MediaForge v1.1.0 迭代（项目交接后）

用户从 GitHub 上抓的 MediaForge 1.0.1 仓库（tanker420/MediaForge），交接给我继续完善。
实际代码库已包含 v1.0.1 的所有修改（A/B/C 级 9 项 + UI 现代化 + 中文打包），所以本次只新增功能与修复下拉 Bug。

### 完成的功能

1. **下拉菜单空白 Bug 修复**（`app/ui/theme.py`）
   - 根因：Qt 6 `QComboBox QAbstractItemView` 设了 `padding: 4px`，popup 顶部多出一行 phantom row
   - 修复：去掉 padding/margin，加 `outline: 0`、`min-height: 18px`
   - 验证：写 `tests/test_combo_popup.py` 守护回归

2. **GitHub 自动更新**（`app/core/updater.py` + `app/ui/update_dialog.py`）
   - GitHub Releases API 检查新版本，流式下载安装包
   - Inno Setup 静默参数 `/SP- /VERYSILENT /CLOSEAPPLICATIONS`，依赖 installer.iss 新增的 AppMutex
   - 启动 3s 后节流检查（24h 内最多一次），顶栏 ⋯ 菜单可手动触发
   - 用户三选一：立即更新 / 仅下载 / 稍后

3. **用户预设 UI 管理**（`app/ui/preset_dialog.py` + `app/core/presets.py` 扩展）
   - 新建（保存当前参数）/ 重命名 / 删除 / 用当前参数覆盖 / 导出 / 导入
   - 文件：`%APPDATA%\MediaForge\presets.json`

4. **媒体预览**（`app/core/media_preview.py` + `app/ui/preview.py`）
   - 图片缩略图：PIL
   - 视频首帧：ffmpeg -ss 10% -frames:v 1 -vf scale=480
   - 音频波形：ffmpeg → 8kHz s16le → 360 buckets RMS（归一化到峰值）
   - 后台线程生成，主线程只画 QPixmap / QPainter

5. **代码签名基础设施**（`packaging/ci/build.ps1` + workflow）
   - 自动探测 Windows SDK `signtool.exe`，签名主 exe + 安装包
   - SHA-256 + DigiCert 时间戳
   - CI 走 Secret `CODE_SIGNING_PFX_BASE64` / `_PASSWORD`，解码后传 build.ps1
   - 缺证书时跳过签名但不报错

6. **版本同步**（`app/__init__.py` + build.ps1）
   - 单一源：`app.__version__`
   - build.ps1 运行时把版本号注入 `version_info.txt` 的 filevers / FileVersion / ProductVersion
   - 编码保持 UTF-16 LE，BOM 兼容 PyInstaller

### 关键决策

- **PyInstaller 钉版** `>=6.3,<7`：7.x 改了 SPEC 注入语义，spec 用了 SPEC 变量
- **Inno Setup AppMutex**：GUID 固定 `MediaForgeAppMutex_7C4B1E36-2F58-4A9D-9E31-5B8A1D0C7F42`，让 /CLOSEAPPLICATIONS 能可靠关闭
- **CLI GBK 编码修复**：`sys.stdout.reconfigure(encoding='utf-8')`，避免 Windows 控制台打印 ✓/✗ 时崩

### 本地打包验证（关键！避免再被 CI 折腾）

- bin/ 放真实 ffmpeg.exe（不能用 scoop shim；用 scoop/apps/ffmpeg/8.1.2/bin/）
- 清理 build/ dist/ 后 `pyinstaller --noconfirm --clean packaging/MediaForge.spec`
- 验证 `_internal/bin/ffmpeg.exe -version` 输出真实版本号
- 跑打包后产物：`MediaForge.exe --cli --version` → `MediaForge 1.1.0`
- 真实转换测试：MKV→MP4，ffprobe 验证 h264 320x240 输出正确

### 隐患 / 待办

- PyInstaller 6.x 在 Python 3.13 上是 6.21.0；CI 用 3.11 应仍 OK
- Inno Setup 在本地未安装，无法本地验证 iss；CI 才会编安装包
- 用户当前代码库不是 git repo（之前网页上传），如要再发版本需要先 `git init` + push
- 机器 scoop 装的 ffmpeg 8.1.2 是真实 242MB 二进制，cp 不带 -f 会被 safe-delete 拦截；用 PowerShell `Copy-Item -Force` 解决
